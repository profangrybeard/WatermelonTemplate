## Key Code Concepts

These are the programming concepts you should understand by the end of this assignment:

### Inheritance – Shared Structure

```csharp
public class TierZero : MergeObject
{
    // TierZero IS a MergeObject
    // It inherits all fields, methods, and merge detection
}
```

Why inheritance? Every merge object needs the same physics, collision detection, and merge logic. The base class provides it once.

### Protected Fields – Family Access

```csharp
// In MergeObject (base class):
protected int tier = 0;
protected string objectName = "MergeObject";
protected int pointValue = 0;
protected float objectSize = 1f;
protected Color objectColor = Color.white;
```

`protected` means: accessible by this class and all classes that inherit from it, but not by unrelated code.

### Virtual and Override – Customizable Behavior

```csharp
// In MergeObject (base class):
protected virtual void Awake() { /* caches components */ }

// In your derived class:
protected override void Awake()
{
    tier = 3;
    objectName = "MyTierThree";
    pointValue = 10;
    objectSize = 0.95f;
    objectColor = new Color(0.9f, 0.6f, 0.1f);

    base.Awake(); // MUST be last — initializes components
}
```

`virtual` means: this method can be replaced by a derived class. `override` means: this derived class is replacing it.

### base.Awake() – Calling Up

```csharp
base.Awake(); // Calls MergeObject's Awake — caches Rigidbody2D and SpriteRenderer
```

Forgetting this call is the most common bug. Without it, physics and visuals will not work.

### Polymorphism – One Type, Many Behaviors

```csharp
// In DropController.cs:
private MergeObject currentObject;  // Could be ANY tier at runtime

// In GameManager.cs:
private List<MergeObject> activeObjects;  // Holds ALL tiers in one list

// Iterating polymorphically:
foreach (MergeObject obj in activeObjects)
{
    obj.GetTier();       // Each object returns ITS OWN tier
    obj.GetPointValue(); // Each object returns ITS OWN points
}
```

One variable type. Many runtime behaviors. That is polymorphism.
